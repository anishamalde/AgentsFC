# Game Plan

The Captain's plan for this match. Not the task, not the trace — the *plan*. Written by the Captain after reading the Match Brief. Everyone downstream (Striker, Defender, Goalkeeper) builds against this.

Think of it as the manager's tactical whiteboard before the whistle.

## Plan template

```
Objective:
<one sentence — what we're trying to achieve>

Grounded facts (from Captain's context retrieval):
- <claim> — <source>
- <claim> — <source>

Approach:
<how the Striker should tackle it, given the facts>

Defenders needed:
- correctness — <why>
- safety — <why>
- style — <why>
(list only the lenses this task actually needs)

Ship policy for the Goalkeeper:
- must pass: <criteria>
- must not contain: <criteria>

Known risks:
- <risk> — <mitigation or accept>

Gaps (things we don't know but need):
- <gap>
```

## Rules

- The Captain writes this ONCE per match, after retrieving grounded facts.
- The Striker reads this to know what to build.
- The Defenders read this to know which lens they own.
- The Goalkeeper reads this to know the ship policy.
- The Manager reads this to know if the play is sensible before it kicks off.
- If the plan changes mid-match, DO NOT overwrite this file. End the match, sub the Captain, start a new match.
