# Manager's Notebook

The Manager's private notes. Reasoning, observations, decisions the Manager makes that aren't for the rest of the squad.

Think of it as the manager's touchline notepad — the audience doesn't see it, but it's how you keep track.

## What goes here

- Why did you pick this Defender lens for this task?
- What did you notice in the Captain's facts that made you skip a Defender?
- Which sub-agent has been reliable this match and which hasn't?
- Notes on sub decisions before you make them (before the sub is logged to `var.md`).
- Patterns you're seeing across plays — things to remember for the next fixture.

## Entry format

Free-form. But timestamp every entry. Keep it readable — future-you will read this.

```
[2026-07-08T14:22Z]
Kick-off. Task looks like a research brief — Captain needs to grab
recent primary sources, Striker needs to write a summary, one Defender on
correctness is probably enough. Leaving style Defender on the bench because
the audience is technical.

[2026-07-08T14:29Z]
Goalkeeper blocked on Defender:safety flag. Reading the finding — it's about
a fact the Captain didn't actually surface, Striker made it up. Not a safety
issue, it's a fact-invention issue. Subbing on a fresh Striker with a
correctness-lens brief instead. Logging sub in var.md.
```

## Rules

- Only the Manager writes here.
- No one else reads this file. It's not part of the audit trail — that's `var.md`.
- If you learn something worth remembering for future matches, promote it to a lesson file (not defined yet — write it up here for now).
